SeizureAlert

Intelligent personal safety monitoring platform designed to support seizure event monitoring and caregiver alerts.

SeizureAlert Web App

Access SeizureAlert directly from your browser to manage your account, review alerts, and use the available monitoring features.

Open Web App

Recommended for desktop browsers. Mobile users may also access the web version directly through their browser.

SeizureAlert Android App

Download the Android application to use SeizureAlert on a compatible Android device.

Download Android APK
Because this application is distributed for testing and academic use outside the Google Play Store, Android may ask for permission before installation.
  1. Download the SeizureAlert APK file.
  2. Open the downloaded file on your Android device.
  3. If prompted, allow your browser or file manager to install apps from this source.
  4. Tap Install and wait for the installation to finish.
  5. Open SeizureAlert after installation.

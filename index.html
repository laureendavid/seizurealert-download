SeizureAlert

Intelligent personal safety monitoring platform designed to support seizure event monitoring and caregiver alerts.

SeizureAlert Android App

Download the SeizureAlert Android application to access the full set of mobile features, including wearer device activation, QR scanning, Bluetooth connectivity, and wearable monitoring.

Download Android APK
Because this application is distributed for testing and academic use outside the Google Play Store, Android may ask for permission before installation.
  1. Download the SeizureAlert APK file.
  2. Open the downloaded file on your Android device.
  3. If prompted, allow your browser or file manager to install apps from this source.
  4. Tap Install and wait for the installation to finish.
  5. Open SeizureAlert after installation.
For Wearers

Activate Your SeizureAlert Device

Scan the QR code below using the SeizureAlert Android application to activate your wearer account and link it with the SeizureAlert wearable device.

SeizureAlert Device Activation QR

How to activate your device

Sign in to the SeizureAlert Android application using your Wearer account. Open the device QR scanner and scan the QR code shown above.

  1. Download and install the SeizureAlert Android App.
  2. Register or sign in using your Wearer account.
  3. Open the device QR scanner inside the SeizureAlert application.
  4. Scan the SeizureAlert device QR code shown above.
  5. Wait for the application to confirm successful activation.
  6. Connect to the Seizure Alert wearable device when prompted.
Important: This QR code is for wearer device activation only. Caregiver connections are managed separately inside the SeizureAlert application.

SeizureAlert Web App

The SeizureAlert Web App is recommended primarily for caregivers who need to monitor their connected wearer's alerts, monitoring information, and available system features.

Open Web App

Some wearer features, including device activation, QR scanning, and Bluetooth connectivity, require the SeizureAlert Android application and are not available through the web version.
